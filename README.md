## 第一次使用：照着做

### 1. 打开程序并登录
双击 EXE，选择 **重新抓取**；已有 tasktoken 可选择 **手动填写**。

### 2. 按抓取页提示打开小程序
确认抓取，处理 Windows 证书提示 → 打开 **Windows 微信电脑版** → 打开校园跑步小程序 → 进入成绩 / 跑步记录页。已打开的页面请刷新或重新进入。

![抓取引导页](docs/screenshots/01-capture.png)

**①** 看到“抓取已开始”后进入小程序；**②** 查看倒计时；**③** 不想继续时取消。成功后 token 自动保存，点击“查看成绩”。超时可重新抓取。

### 3. 检查腾讯 Key
右上角 **设置** 可填写自己的 WebService Key 和 JavaScript GL Key。

默认已填入：`JXIBZ-7IQ6I-AJPGJ-UZFYM-NSBRO-YQFPT`。

**这个 Key 未来可能无法使用，建议自行申请一个。** 内置值不代表已验证其权限、额度或持续可用性。已有自定义 Key 不会被覆盖。自行申请请打开[腾讯位置服务控制台](https://lbs.qq.com/dev/console/key/manage)，按控制台说明配置对应产品权限；两个输入框可使用各自的 Key。

### 4. 开始规划
点击右上角 **开始跑步**，等待打卡点和路线显示。

![路线规划页](docs/screenshots/02-route.png)

**①** 设置公里数；**②** 按需开启抖动，设置幅度、平滑点数和种子；**③** 修改参数后点“刷新路线”；**④** 检查路线、配速和时长，满意后“确认运行”。

### 5. 查看进度和请求日志

![任务执行页](docs/screenshots/03-execution.png)

**①** 进度；**②** 请求日志；**③** 失败等待时可立即重试；**④** 停止任务。临时网络故障会自动等待重试；创建会话或鉴权失败需手动处理。显示完成不等于平台审核通过，成绩以平台为准。

> 截图来自本程序的离线演示界面，蓝色编号为说明标注。账号、成绩和请求为演示数据；路线图是离线示意，不是腾讯在线底图。

## 记住这几点

- 配置文件：用户目录 `config.json`；token 属于敏感信息，请勿分享。
- 地图依赖系统 WebView2 Runtime；地图启动失败时先检查该组件、网络和 Key 权限。
- “免安装”指本软件；首次自动抓取仍需确认安装 mitmproxy 根证书和临时代理。结束、取消或退出时恢复原有代理；证书不会随抓取结束自动移除。不再抓取时可在 Windows 证书管理器中核对后删除对应 mitmproxy 根证书。
- 抓取时小程序联网异常：先取消抓取，点击右下角“恢复代理”，再重试或手动填写 token。
- 升级：退出旧程序，替换 EXE。免安装版仍会保存本地配置，不等同于零文件写入。
